## 남은 장치 검증과 적용

Raspberry Pi 4 8GB에는 접근하지 않았으므로 장치의 6GB 한도, ARM 환경 설치, 다른 서비스와 동시 운영할 때의 OOM 여부는 **미검증**이다. Windows 결과를 Pi 적합성 증거로 대체하지 않는다. Pi에서 README의 평가 명령과 실제 색인·검색 부하를 실행하고 메모리를 측정해야 한다.

개발 PC의 공개 모델은 `D:/Models/BAAI/bge-m3`에 준비했다. 보호된 환경 파일은 열거나 수정하지 않았고, 서비스 환경 설정과 운영 DB 마이그레이션은 적용하지 않았다. 서비스 환경에 모델 경로와 CPU를 지정한 후 정상 시작하면 신규 마이그레이션과 백그라운드 청크 색인이 실행된다. 실행 중에는 모델을 다운로드하지 않는다.
